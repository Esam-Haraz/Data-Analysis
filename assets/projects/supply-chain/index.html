Business question & goals

This analysis evaluates 25,000 shipment records from a public Kaggle logistics dataset (~5,000 shipments per region) to identify what separates on-time deliveries from delayed or failed shipments.

The investigation focuses on four operational areas: weather conditions, delivery partner and vehicle combinations, shipping modes (such as Express), and how delivery cost scales with shipment distance.

Analysis pipeline

Workflow from raw CSV inspection to interactive Excel filtering and PostgreSQL verification.

Step 01 25%

Raw CSV

Loaded 25,000 shipment rows and audited identifier uniqueness, shipment statuses, distance, weight, and timing columns.

Step 02 50%

Excel cleaning

Standardized fields in Excel, preserved the original dataset untouched, and flagged zeroed time columns before analysis.

Step 03 75%

PostgreSQL

Created a relational table with a serial primary key and executed 9 analytical queries covering delays, costs, ratings, and distance bands.

Step 04 100%

Excel dashboard

Built Pivot Tables and an interactive dashboard with slicers for Delivery Partner, Region, and Delivery Mode.

Key findings

Dataset baselines: 25,000 shipments (~5,000 per region), 26.68% delay rate, 864.94 average delivery cost, 3.67/5 average rating, 150.39 km average distance, and 25.15 kg average weight.

Stormy and rainy weather more than double shipment delay rates compared to clear and cold weather.

Data quality & limitations

Documented dataset issues handled during preparation:
  • The source delivery_id column contained duplicate entries and decimal values, so a surrogate row_id SERIAL primary key was generated in PostgreSQL while preserving the original dataset intact.
  • Both delivery_time_hours and expected_time_hours consisted entirely of zeros across all rows, making it impossible to answer the planned delivery time gap question.

How to reproduce

  1. Clone or download the GitHub repository containing the raw dataset and project folders.
  2. Open the Excel/ folder to inspect the cleaned spreadsheet, Pivot Tables, and interactive slicer dashboard.
  3. Create a PostgreSQL database and run the table creation script inside the SQL/ folder before importing the dataset.
  4. Execute the remaining analytical scripts in the SQL/ folder to reproduce all delay, cost, rating, and distance metrics.
