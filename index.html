How I work

Every project follows a reproducible four-stage pipeline from raw table inspection to final visual reporting.

Step 01

Raw data

Inspect source CSV files, row counts, data types, and primary key integrity before writing queries.

Step 02

Clean

Standardize fields in Excel or Power Query, resolve key issues, and record any unusable columns.

Step 03

Analyze

Run structured SQL queries and Pivot summaries to isolate patterns, segment differences, and outliers.

Step 04

Dashboard

Present verified findings in focused Excel or Power BI dashboards with interactive filters.
